  <h1>Giza Sphinx: Stratigraphic Matrix & Dual Aesthetic Suite</h1>
  <p>A web-based 3D spatial visualization and digital humanities application exploring the monumental history, geomorphology, and cultural folklore of the Great Sphinx of Giza. Designed with an interactive stratigraphic time slider, dual aesthetic themes (Antique Rustic and Cyber Futuristic), procedural Web Audio soundscapes, and integrated geospatial mapping.</p>
  
  <hr>

  <h2>Key Features</h2>
  <ul>
    <li><strong>Interactive 3D Viewport (Three.js):</strong> Custom procedural 3D sculpture of the Sphinx monolith, pharaonic headdress, and surrounding Old Kingdom mastabas with orbital camera controls and raycasting hotspot inspection.</li>
    <li><strong>Stratigraphic Era Slider:</strong> Traverse through four major historical phases:
      <ul>
        <li><strong>01. Old Kingdom (c. 2500 BCE):</strong> Freshly carved limestone with brilliant red/yellow ochre plaster.</li>
        <li><strong>02. New Kingdom (c. 1400 BCE):</strong> Partial sand accumulation and Thutmose IV's Dream Stele.</li>
        <li><strong>03. Medieval Era (c. 1378 CE):</strong> Folklore, agricultural flood talismans, and post-iconoclastic sand dune encroachment.</li>
        <li><strong>04. Modern Conservation (Present):</strong> Contemporary stone masonry restoration and laser photogrammetry.</li>
      </ul>
    </li>
    <li><strong>Dual Aesthetic Modes:</strong> Switch seamlessly between an <strong>Antique Rustic</strong> scholarly palette and a <strong>Cyber Futuristic</strong> telemetry UI.</li>
    <li><strong>Web Audio API Soundscapes:</strong> Procedural brown-noise desert wind synthesis with dynamic low-pass filtering and resonant acoustic oracle echo tones.</li>
    <li><strong>Geospatial Telemetry (Leaflet.js):</strong> Embedded interactive satellite map archive pointing to precise coordinates on the Giza Plateau.</li>
  </ul>

  <h2>Tech Stack</h2>
  <ul>
    <li><strong>3D Graphics:</strong> <a href="https://threejs.org/" target="_blank">Three.js</a> (r128) & OrbitControls</li>
    <li><strong>Mapping:</strong> Leaflet.js with ArcGIS World Imagery tiles</li>
    <li><strong>Audio:</strong> Native Web Audio API (Nodes, BiquadFilters, LFOs, Delay networks)</li>
    <li><strong>Styling & Markup:</strong> HTML5, CSS3 Grid/Flexbox with CSS Custom Properties</li>
  </ul>

  <h2>Local Installation & Usage</h2>
  <p>This project is fully self-contained in a single HTML file for lightweight deployment and local testing.</p>
